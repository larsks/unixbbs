This BBS includes a CBM (Commodore) BASIC interpreter.

To start the interactive interpreter:

    basic

To execute BASIC code in a text file:

    basic myfile.bas

To exit the interpreter:

    QUIT

Example program:

    Note that all BASIC syntax must be IN UPPER CASE.

    10 GOSUB 100
    20 INPUT "What is your name"; A$
    30 PRINT "Hello, "; A$; "."
    40 GOSUB 100
    50 END

    100 FOR X = 1 TO 40
    110 PRINT "=";
    120 NEXT X
    130 PRINT
    140 RETURN
